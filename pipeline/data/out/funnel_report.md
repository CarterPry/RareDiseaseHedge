## How to read this

The **orphan-flagged, multi-regulator, INN** candidates are the highest-value rows: an INN exists (mature molecule), more than one stringent regulator approved it (real drug, real dossier), and at least one called it orphan (already in rare-disease territory). Start manual review there.

### Known residual error classes (do not skip)

- **US exclusion set is NDA-based.** Drugs@FDA + Orange Book do NOT include OTC-monograph, pre-1938, or DESI-withdrawn drugs. So a moiety marketed in the US only under an OTC monograph (e.g. aspirin) can still surface as a false candidate. This is the § 2 completeness gap in the method doc. It also intersects the *Sun Pharma* A2 population, so treat these as 'investigate', not 'discard'.

- **Prodrugs still leak.** Salt/base collapse is handled via moiety-UNII, but a prodrug whose active moiety is US-approved under a different parent (e.g. isavuconazole vs US-approved isavuconazonium) is not caught without the GSRS active-moiety graph. A minority of rows; flag prodrug/ester names in manual review.

- **EMA is centralised-only.** Nationally-authorised EU drugs are absent, so some 'never-US' calls may actually be approved via an EU member state.

- **Japan is under-covered.** Only PMDA FY2025 (~140 rows) is loaded and katakana names mostly fail to resolve without a transliteration layer. The true Funnel A pool is larger and concentrated in exactly this highest-yield source — building the JP→UNII transliteration layer is the top next step.

- This diff does NOT test the § 360ff(a)(3) rare-pediatric gate, FTO, or existing orphan exclusivity. It narrows thousands of approvals to a hand-reviewable list; the human work starts here.

**What this is:** active substances approved by a foreign regulator whose active moiety is absent from the entire US approval record — i.e. the population A1 (never approved in the US) that § 360ff makes PRV-eligible. This is a *screening list*, not a clearance; downstream filters (505(b)(1) fileability, rare-pediatric evidence, FTO, orphan-exclusivity conflict) still apply. The matcher is measured, not asserted: `python3 pipeline/test_accuracy.py --real` replays labeled known-answer drugs through this exact code path.

## How to read this

The **orphan-flagged, multi-regulator, INN** candidates are the highest-value rows: an INN exists (mature molecule), more than one stringent regulator approved it (real drug, real dossier), and at least one called it orphan (already in rare-disease territory). Start manual review there.

### Known residual error classes (do not skip)

- **US exclusion set is NDA-based.** Drugs@FDA + Orange Book do NOT include OTC-monograph, pre-1938, or DESI-withdrawn drugs. So a moiety marketed in the US only under an OTC monograph (e.g. aspirin) can still surface as a false candidate. This is the § 2 completeness gap in the method doc. It also intersects the *Sun Pharma* A2 population, so treat these as 'investigate', not 'discard'.

- **Prodrug/conjugate exclusion now runs via GSRS** (two hops along ACTIVE MOIETY / PRODRUG / SALT-PARENT edges) and catches the isavuconazole-class leaks the string layer measured. It depends on the GSRS graph being complete for the substance; a missing GSRS edge is a missing exclusion, so prodrug-looking names in the candidate list still deserve a manual glance.

- **EMA is centralised-only.** Nationally-authorised EU drugs are absent, so some 'never-US' calls may actually be approved via an EU member state.

- **Japan is under-covered.** Only PMDA FY2025 (~140 rows) is loaded and katakana names mostly fail to resolve without a transliteration layer. The true Funnel A pool is larger and concentrated in exactly this highest-yield source — building the JP→UNII transliteration layer is the top next step.

- This diff does NOT test the § 360ff(a)(3) rare-pediatric gate, FTO, or existing orphan exclusivity. `pipeline/eligibility.py` walks all ten statutory criteria per candidate and labels which a human must decide; it never returns 'eligible', only 'nothing has ruled it out yet'.

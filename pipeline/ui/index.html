Known limitations — read before acting

Four residual error classes
  • US exclusion set is NDA-based. Drugs@FDA + Orange Book exclude OTC-monograph, pre-1938 and DESI-withdrawn drugs, so a monograph-only moiety (e.g. aspirin) can appear as a false candidate. This also intersects the Sun Pharma pre-1962 carve-out population — treat these as “investigate,” not “discard.”
  • Prodrugs can leak. Salt/base forms collapse correctly, but a prodrug whose active moiety is US-approved under a different parent (isavuconazole vs US-approved isavuconazonium) is not caught without the GSRS active-moiety graph.
  • EMA is centralised-only. Nationally-authorised EU drugs are absent, so a “never-US” call may in fact be approved via an individual EU member state.
  • Japan is under-covered. Only PMDA FY2025 loads and katakana names mostly fail to resolve without a transliteration layer — the highest-yield source is the least complete here.
